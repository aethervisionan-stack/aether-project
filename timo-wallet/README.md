# Timó — demo de carteira digital

App web estilo fintech brasileira (conta digital / carteira pessoal) com saldos, PIX, cartões, transferências, extrato e perfil. Dados 100% mockados para análise de UX/UI.

## Rodar local

```bash
cd timo-wallet
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Telas

- **Início** — saldo, atalhos, contatos e movimentações
- **Área PIX** — enviar, receber (QR), chaves
- **Cartões** — virtual/físico, limite, bloquear, revelar dados
- **Transferir** — PIX/TED para contatos
- **Extrato** — filtros e busca
- **Perfil** — dados da conta e menus
- **Pagar / Depositar** — boleto e dados bancários
